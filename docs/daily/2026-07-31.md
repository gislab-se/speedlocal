## Decisions and discoveries

- Frozen V2 aggregates all 13,851 valid R7 distance rows to each H3 parent
  using minimum distance and any intersection, then filters to the public
  target domain. Filtering to the 13,735 public R7 cells first would change
  minimum distance in three R6 and two R5 public parents.
- The public R7 display cells derive exactly 2,163 R6 parents and 365 R5
  parents. Those reviewed display files now form manifest-declared rollup
  contracts rather than app-code path constants.
- The existing checksum-pinned 45-file cloud package already contains the R7
  distance table and both coarser display files. No runtime inventory, ZIP, or
  Release change is required for this checkpoint.
- H3 resolution is a discrete contract. Boolean, string, fractional,
  undeclared, upward, and mixed-resolution requests fail closed rather than
  being coerced.
- The Streamlit bridge delegates canonical-domain validation to
  `speedlocal.run_analysis`; it does not parse the large domain twice or
  select an algorithm from a region id.
- The delivery schedule moved one business day because the roads slice is not
  locally promoted until `roads_medium`, combined behavior, and obsolete-path
  removal pass.
- The publication cadence is now explicit: normal development checkpoints go
  to `v2-final-dev`; `main` is the published branch. Friday is the normal
  publication window and Tuesday is optional for a coherent locally promoted
  increment. An emergency outside those windows requires a recorded reason.
