### Decisions and discoveries

- Commit `5e1dab1` removes the implicit Trøndelag fallback from migrated wind
  helpers. The still-transitional acceptance registry retains its own default
  only for unmigrated groups and will be removed slice by slice.
- Trøndelag `population_points` is a legacy id for a dissolved MultiPolygon
  built from 26,029 occupied 250 m grid-cell centroids. Its declared data
  representation is therefore `grid`, and geometry detection is `polygon`.
- The source preview is polygonal, but the accepted numeric distance artifact
  is centroid-based H3 R8 with 89,312 rows. This limitation must remain visible
  in the manifest and UI; it must not be hidden by a region-name algorithm.
- The public analysis domains remain R7/R6/R5, so the layer contract needs an
  explicit distance-artifact resolution and raw-first parent rollup.
- The R8 population artifact intentionally leaves 256/26/7 canonical cells
  uncovered at R7/R6/R5. Frozen V2 leaves their distance missing, does not mark
  them geometrically blocked, and assigns zero acceptance. The population
  manifest therefore pins exact sparse-coverage signatures and a
  `zero_acceptance` missing policy; undeclared coverage drift still raises.
- The complete archive and checksum-pinned public runtime package already
  contain the required source and distance files. No old-computer import or
  runtime transport change is required for the first population increment.
- At 500 m, frozen primary-population mean potential is
  66.1171676447033%/45.2247388811835%/22.3069857534247% at R7/R6/R5, with
  4,048/1,125/278 zero-acceptance cells respectively. True
  distance/intersection-blocked counts are 3,792/1,099/271.
- The primary wind population control, numeric restriction, source preview,
  and buffer preview now use the manifest and shared resolver. A missing
  migrated UI/layer contract raises before `population_points` can be treated
  as a legacy source.
- Sparse zero-acceptance completion is permitted only for an exact declared
  target resolution and canonical analysis domain. Contract validation also
  requires the signed R7/R6/R5 targets and counts to match that domain.
- Optional `built_centre` and `built_low_selection` inputs remain on the
  transitional registry. Mixed source/buffer review is therefore deferred;
  the canonical primary layer can be reviewed alone. The separate wind
  allocation-ranking consumer also still reads the legacy population table and
  is not part of this primary restriction increment.
